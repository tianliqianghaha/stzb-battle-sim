# 率土之滨 · 各阵营大小保底卡池（多源共识版）

> 用途：作为后续「配将卡池」的武将来源与价值分层参考。
> 分层含义：大保底 = 半价/核心五星（价值高，优先围绕建队）；小保底 = 免费/素材五星（价值偏低，多用于拆战法或拼图）。
> 维护日期：2026-11-01 ｜ 验证方式：跨源比对（见文末来源与置信度）。

---

## 一、保底机制：官方规则 vs 玩家共识（务必分清楚）

**① 官方明确规则（可信）**
- 阵营名将卡包每招募 5 次必获赠 1 张 3–5 星武将卡，次数在阵容轮换后继承。
- 每日 0 点及阵容轮换时，刷新 1 次免费 + 1 次半价机会。
- 轮换顺序：**魏晋名将 → 蜀汉名将 → 群雄名将 → 东吴名将 → 循环**，每日中午 12 点轮换。
- 不同卡包保底次数互不叠加；同一卡包跨赛季不清零；卡包下架即重置。

**② 玩家共识的「大小保底」（非官方硬规则，属观测规律）**
- 小保底：约 30–40 抽必出五星，多为「素材/免费池」五星（价值低）。
- 大保底：约 95–120 抽高概率出核心「半价池」五星（价值高）。
- 节奏：约 2–3 次小保底后出 1 次大保底；小保底清零不影响大保底计数，大保底清零连带重置小保底。
- 另有「累计 100 次必出当期高价值五星」说法流传，未经官方确认，列为参考。

**③ 重要区分：阵营名将卡包 ≠ 天下卡包**
- 阵营名将卡包：只出单一阵营五星，按上面轮换，是日常免费/半价主投放口；**没有独立的「晋」轮换位，晋将并入「魏晋」名下**。
- 天下卡包（剧本卡包，如新势初起、天下大乱、厉兵秣马、群雄割据、乱世英雄、逆取顺守等）：跨阵营混编，每版本调整。十周年（2025-10-10 官方公告）已新增【汉·曹操/孙坚/刘备】、【蜀·姜维XP】、【晋·司马懿XP】、【吴·孙权XP】，并移除【蜀·夏侯霸XP】【群·吕姬】【汉·貂蝉】【群·董白】【魏·王朗XP】【魏·郭皇后】。
- 本文名单针对**阵营名将卡包**口径；用做配将池时若含天下卡包，需叠加上述增删。

## 三、给配将卡池使用者的提醒

- **阵营判定是客观的**（每张卡有固定阵营属性），本名单的阵营归属可直接作为配将缘分/阵营加成依据。
- **大/小保底分层是玩家共识、非官方**，本质是「核心(半价) vs 素材(免费)」的价值经验分层；作为配将优先级信号可用，但禁止当作引擎/游戏硬规则。
- **晋阵营全部为大保底**（仅卫瓘为小保底），核心密度最高；玩家共识也推荐优先在「魏晋」日吃保底。
- **名单可能漏收绝版/新增武将**，且十周年后天下卡包有增删（见第一节③）；入库为配将池前，建议以游戏内当前卡包说明为最终准。
- **「大核心卡池需赛季充值门槛（如 648）才出货、月卡党多落小核心」** 仅为单玩家长期统计【存疑】，未获证实，勿据此排除武将。

## 五、已机器化接入（机读配将池）

**产出文件**：`docs/配将卡池.json` —— 模拟器可直接读取的配将卡池。
**生成脚本**：`scripts/build-pity-pool.py`（可复现：读桌面 xlsx + 引擎 `hero.json` + 本共识 md → 产出 json）。

**核心数据规则（务必遵守）**
- **英雄可跨阵营，唯一判别 = (阵营, 英雄, 星级)**：如 吕布=汉/群、关羽=蜀/魏、司马懿=魏/晋、贾诩=魏/群，每一组合独立成一条记录。桌面 xlsx 已用分两行的方式正确处理了这一区分（如吕布 汉 100003 / 吕布 群 100010）。
- **同键变体合并**：基卡 / SP / 赛季变体 共享同一 (name, 阵营, 星级)，全部 `hero_id` 合并进 `heroIds[]`。
- **引擎 id 以 `hero.json` 为准**：xlsx 的「武将ID」与 hero.json 的 `hero_id` 并非 100% 对齐（已发现 许褚 xlsx=100840 / 引擎=100473、刘秀 引擎无收录），故引擎 id 一律按 (name, country, quality=5) 回 hero.json 解析，xlsx 的 id 仅作参考记录。
- **分层字段**：`tier` ∈ 大保底 / 小保底 / 未分级；`confidence` 仅大/小保底带（consensus / single-source）。

**接入结果（生成时快照）**
- 总条目 159（xlsx 去重 154 + 共识补录 5）；引擎可用 158，仅 `刘秀(汉)` 引擎无收录（`engineAvailable=false`）。
- 大保底 77 / 小保底 49 / 未分级 33。
- 共识列级但 xlsx 未收录、已从 hero.json 补录的 5 条：夏侯霸(蜀)、华佗(汉)、庞德(群)、于吉(群)、群贾诩(群)。
- **唯一未解决**：`步诸葛(蜀)` 在两源均无五星记录（共识疑似误记，吴将 步皇后/步练师 与之易混），保留在 json 的 `unresolved` 字段待人工复核。

**给后续 AI 的使用指引**
- 配将时按 `faction` 筛选可用阵营，按 `tier` 决定优先级（大保底优先建队核心、小保底/未分级作拼图或拆战法）。
- 取将用 `heroId`（优先基卡）；需要变体时用 `heroIds[]`。
- 重新生成：`python3 scripts/build-pity-pool.py`（桌面 xlsx 路径若变，改脚本顶部 `XLSX_PATH`）。
