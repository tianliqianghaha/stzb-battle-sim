## 〇、方法学与诚实声明（先讲清口径，结论才有意义）

- 参战阵容
  - T0：引擎内置 `web/data/opponent_benchmark.json` 的 **8 支基准**（2026-10-10 版本）。
  - T1：**9 支**网搜 2026 共识队（网易大神 @永远配将《2026下半年112队强度榜》、@小白板《26年八大白板战神》等），用引擎忠实还原，落库于 `docs/t0t1_roster.json`：黄盖法刀 / 王异法刀 / 程昱魏智 / 甘宁士气流氓 / 张飞流氓 / 庞统蜀步 / 曹彰撸铁 / 马超菜刀 / 周瑜嘟嘟。
  - 合计 **17 队**，覆盖主流流派：神赏法刀、魏智、流氓、肉步、撸铁、菜刀、嘟嘟，以及 T0 的 吕布爆发 / 张春华减伤体系 / 太史慈菜刀 / 祝融象兵。
- 公平性归一（关键）
  - 为隔离「流派机制」本身、排除投资差干扰，全部队伍统一 **40 级 · 白板（红度0）· 士气120 · 无宝物**。
  - 即：本报告的胜率不是官方天梯，而是「同等投入下，各流派机制在 8 回合引擎内的相互克制关系」。
- 模拟口径
  - 17 队全配对 × 双向（攻方/守方各半）× 80 种子 = **10880 场**。
  - 每场从 `BattleReport.events` 事件流提取底层指标，再聚合。
- 三个必须直说的诚实点
  - ① 全混战是 17 队大循环，单队胜率天然偏低、平局偏高（8 回合上限 + 双方常同归于尽式存活）。**胜率只是相对强弱的代理，不是官方梯队**。
  - ② 引擎内置的 8 支 T0 基准是「制作人固定测试集」，白板归一后**内部极差极大**（荀彧张春华曹操 0.2%、太史慈曹植关羽 0.9% vs 祝融张辽曹操 42%）——其中几支在白板下明显偏软。
  - ③ 因此真正回答「为什么是 T0 / 为什么是 T1」的，不是原始胜率，而是下面的**底层维度剖面**（增伤链 / 减伤链 / 爆发窗口 / 控制 / 续航 / 发动率）。

## 一、核心结论（一句话定律）

> **T0 的本质 = 增伤引擎（神兵天降 / 大赏三军 / 攻其不备 / 垒实） ×（前3回合爆发窗口 或 减伤+续航兜底）的乘法效应。**
> **缺「增伤引擎」这一环 → 退化为高非败、低胜率的「乌龟/控制流」（T1 乃至 T2 行为）；有增伤但缺「爆发或续航」→ 不稳，胜率波动大。**

这条定律由全量底层数据反推，且与项目固化经验 `AGENTS.md` 里的 **E5 权威因子排名（战法 33.5% > 加点 12.9% > 站位 8.7% > 宝物 7.8% …）** 完全自洽——「增伤体系」正是战法因子里权重最高的那一块。

## 四、从最底层数据反推的规律

### 规律①：增伤引擎是 T0 / T1 的真正分水岭（最核心）

- 增伤链（神兵天降+大赏三军 / 攻其不备 / 垒实 等施加的 caused+taken 归因，按伤害事件累计）与胜率强相关：
  - 增伤链 ≥ 1000% 且伤害输出高的队：祝融张辽曹操 2744%→42%胜、马超菜刀 1631%→37%、甘宁士气 980%→43%、程昱魏智 1069%→34%、周瑜嘟嘟 740%→41%、张春华乐进于禁 1014%→15%（但靠减伤托底）。
  - 增伤链极低的队：荀彧张春华曹操 **-0.2%**→0.2%胜、太史慈曹植关羽 **1.2%**→0.9%胜、太史慈张春华周泰 113%→2.6%胜。
- 结论：**没有增伤引擎，再强的控制、再厚的减伤，也只换来「高非败、零胜率」的乌龟**。荀彧张春华曹操 非败 75.6% 但胜率 0.2%——它把对手拖到死也打不死对方。
- 与 E5 因子排名吻合：战法（增伤体系）权重 33.5% 居首，底层数据印证它就是梯队分水岭。

### 规律②：爆发窗口 与 续航兜底，是「增伤」转化为「胜率」的两个出口

- 有增伤 + 前3回合高爆发（≥55%）：祝融张辽曹操 68.4%、马超菜刀 61.4%、周瑜嘟嘟 59.5%——靠「8 回合内先打死你」取胜，胜率高但非败略低（一旦没秒掉易反被拖）。
- 有增伤 + 厚续航/减伤（后发）：庞统蜀步（爆发仅 30.9% 但 续航出 10817 + 减伤链 1367%）、甘宁士气（减伤链 1270% + 续航 3582）、张飞流氓（减伤链 851% + 续航 7709）——靠「你打不死我、我慢慢磨死你」，非败极高（86~89%）、胜率中等、平局多。
- 缺爆发又缺续航的增伤队：王异/黄盖法刀（增伤 537~633%、减伤仅 413~428%、续航 0）→ 胜率掉到 8~9%，非败虽 78~80% 但打不出胜负。

### 规律③：纯控制 / 纯减伤是「非致命陷阱」

- T0 基准平均控制出 8.13、T1 平均仅 4.64——T0 基准更依赖张春华体系的控制（吕布张春华甄洛 控制出 14.47、张春华乐进于禁 12.94、荀彧张春华曹操 11.05）。
- 但控制高 ≠ 胜率高：吕布张春华甄洛 非败 91.6% 但胜率仅 25.8%；荀彧张春华曹操 控制 11.05 但胜率 0.2%。
- 机制解释：**控制只创造输出窗口，不创造输出本身**。没有增伤引擎把窗口变成杀伤，控制流就是「按住对手、然后互相瞪眼到 8 回合」。

### 规律④：平局成因 = 8 回合上限 + 双方同存活

- 全量平局率 50~80%，几乎都出现在双方残血共存到 R8。
- 平局均剩兵普遍 9000~18500（即两队都还剩一大截兵力），典型如张飞流氓平局均剩兵 18178、庞统蜀步 18574——**打不完**是平局主因，而非「势均力敌的精准互换」。
- 这印证引擎 8 回合上限放大了「消耗/乌龟」队的价值（也是上一轮小保底论证里提到的同一条规律）。

### 规律⑤：场均伤害类型揭示流派 DNA

- 纯物理天花板：曹彰撸铁 24912、祝融张辽曹操 25497、马超菜刀 22702、张飞流氓 18110。
- 纯谋略天花板：周瑜嘟嘟 18079、程昱魏智 16912、甘宁士气 4887(偏物)。
- 混合/偏防：庞统蜀步（物10929/谋8528）、吕布张春华甄洛（物18102）。
- 伤害越低越易掉梯队：太史慈曹植关羽 11243、荀彧张春华曹操 10206——输出垫底直接锁死胜率。

## 五、流派剖析（回答「为什么这些队是 T0 / 为什么是 T1」）

  - 短板：减伤薄（267~603%），非败率中等，遇厚减伤/续航队易平。
- 神赏法刀（周瑜嘟嘟、王异/黄盖法刀）

  - 王异/黄盖法刀为什么掉到 T1 下沿：增伤仅 537~633%、减伤 413~428%、无续航 → 既不够爆发也不够肉，胜率 8~9%。说明**同是法刀，增伤链厚度差一倍，梯队差一档**。
- 魏智（程昱魏智）
  - 三核谋略 + 增伤 1069% + 控制 9.69（全场最高控制），靠控制+增伤双引擎稳居 T1 中上游（33.5%胜、81%非败）。
- 流氓（甘宁士气、张飞流氓）
  - 甘宁士气：神赏增伤 980% + 减伤 1270% + 续航 3582 → 攻防续三件套，43%胜/86%非败。
  - 张飞流氓：爆发仅 26.7%、但减伤 851%+续航 7709 + 增伤 460% → 极致「打不死」，5%胜但 89%非败、84%平——它是「平局制造机」而非「胜场机器」，本质是 T1 偏防御向。
- 肉步（庞统蜀步）
  - 增伤 466% 不算高，但减伤链 1367% + 续航 10817（全场最高恢复）把「消耗」做到极致，43%胜/87%非败，且 vsT0 胜 60%——**白板下最稳的克制者之一**。
- 撸铁（曹彰撸铁）
  - 纯物理伤害 26332（全场最高）+ 减伤链 1034% → 又猛又硬，74%胜/94%非败，是本次白板混战的「版本之子」。但需注意：它强在曹彰+木鹿+曹操的物系联动，红度上去后更恐怖。
- 张春华减伤体系（吕布张春华甄洛、张春华乐进于禁、荀彧张春华曹操、太史慈张春华周泰）
  - 共同短板：**增伤链薄或为零**（吕布队 353%、荀彧队 -0.2%）。张春华的浑水/始计/减伤把非败托高，但缺乏增伤引擎 → 胜率天花板低（0.2%~25.8%）。这是内置 T0 基准里「白板偏软」的群体，也是为什么 T1 平均压制 T0 的根因之一。
- 太史慈系（太史慈曹植张辽、太史慈曹植关羽、太史慈张春华周泰）
  - 增伤链 1~498%，输出垫底或承伤最高 → 白板下全面塌陷（0.9%~6.2%胜）。说明**太史慈菜刀若没有神赏增伤引擎支撑，在白板环境就是 T2 行为**。

## 六、典型对局逐回合深拆（4 组，底层数据讲机理）

### 案例A：曹彰撸铁(T1) vs 荀彧张春华曹操(T0软肋)
- A 视角结果分布：胜 34 / 负 0 / 平 6（**胜率 85%**，0 败）
- 代表种子 7097（A 胜，R7 结束）
- 回合兵力（我/敌，三将）：
  - R1 [7978/9000/8360 ｜ 9000/9000/8660] → R4 [6988/7842/6886 ｜ 2166/3978/3016] → R7 [5896/7501/6003 ｜ **0/2332/0**]
- 机理：撸铁靠「曹彰一骑+令无空悬」纯物理 26332 均伤 + 减伤链 1034% 硬抗，把零增伤的乌龟队（荀彧队增伤 -0.2%）逐回合磨穿。印证**规律①+②：有增伤/高伤+减伤兜底，能碾碎纯控制乌龟**。

### 案例B：祝融张辽曹操(T0) vs 吕布张春华甄洛(T0)
- A 视角结果分布：胜 7 / 负 10 / 平 23（胜率 17.5%，高平局）
- 代表种子 7128（A 胜，R8 结束）
- 回合兵力：
  - R1 [9000/8671/8203 ｜ 8603/8298/8580] → R3 [8795/7183/7435 ｜ 6258/2619/3054] → R8 [7408/5220/6092 ｜ **0/0/0**]
- 机理：两支都是「神赏增伤+前3回合爆发」队（祝融队爆发 68.4%、增伤 2744%）。双方前3回合互砍，祝融队增伤链更厚、爆发更早，最终 R8 清空吕布队。**印证规律②：同属爆发型，增伤链厚度/先手决定谁先打死谁；势均力敌则拖成平局（23/40）**。

### 案例C：庞统蜀步(T1) vs 荀彧张春华曹操(T0软肋)
- A 视角结果分布：胜 9 / 负 0 / 平 31（**0 败**，胜率 22.5%）
- 代表种子 7159（A 胜，R8 结束）
- 回合兵力：
  - R1 [8630/8983/8736 ｜ 7925/7933/8737] → R5 [7185/8415/6944 ｜ 6066/1520/6916] → R8 [6946/8408/6810 ｜ 0/0/3586]
- 机理：蜀步前3回合爆发仅 30.9%（后发），但减伤链 1367% + 续航 10817 让它全程不掉血；乌龟队（荀彧）控制 11.05 却零增伤，越打越虚，R8 被磨穿。**印证规律①+③：控制流按住蜀步却打不死，反被续航磨死；蜀步「0 败」就是消耗流的体现**。

### 案例D：张飞流氓(T1) vs 太史慈曹植关羽(T0软肋)
- A 视角结果分布：胜 2 / 负 0 / 平 38（**0 败**，胜率 5%）
- 机理：太史慈曹植关羽增伤链仅 1.2%（几乎无增伤引擎），输出垫底（11243）；张飞流氓增伤 460%+减伤 851%+续航 7709。双方都打不死对方 → **38/40 平局**。张飞流氓「5%胜/89%非败/84%平」正是规律②的极端样本：**有增伤+续航但缺爆发 → 平局制造机**。

## 七、对「为什么是 T0 / 为什么是 T1」的最终回答

- 是 T0 的队伍（在白板归一下仍强）：共同骨架是 **增伤引擎 ≥ 700%（神赏/大赏/攻其不备）+（前3回合爆发 ≥55% 或 减伤链 ≥1000%+续航）**。祝融张辽曹操、吕布张春华甄洛、周瑜嘟嘟、马超菜刀、程昱魏智、甘宁士气、庞统蜀步、曹彰撸铁 都至少满足其中一条强路径。
- 退化为 T1 / T2 行为的队伍：缺增伤引擎（荀彧张春华曹操 -0.2%、太史慈曹植关羽 1.2%、太史慈张春华周泰 113%）、或增伤薄且又无减伤续航兜底（王异/黄盖法刀 537~633% 增伤、减伤仅 413~428%、无续航）。它们可以靠控制/减伤把非败托到 75~92%，但胜率被锁死在 0~9%。
- 一句话：**T0 与 T1 的分野不在「控制多不多、减伤厚不厚」，而在「有没有把控制/减伤窗口转化为实际杀伤的增伤引擎，以及有没有爆发或续航把这口伤害兑现成击杀」**——这正是底层数据反复验证的本质规律。
