## 四、全部已发现规律在组队中的落地
- **N1 物理输出驱动胜率**：3 队均选物理/法系高成长核（庞德/沙摩柯/荀彧），并配增伤链把"输出"转化为胜率；法系队用神兵大赏把谋略输出拉满。
- **N2 增伤膝点**：每队必带增伤链（神兵天降+大赏三军 / 攻其不备 / 一骑当千+击势），确保增伤>0.2 越过胜率硬地板。
- **N3 减伤饱和**：减伤只给前锋（垒实/战必/避其），用于"非败"而非堆胜率，避免浪费因子。
- **N4 增伤差决定胶着**：增伤链强度压过 T0 常见增伤，减少平局（平局仅计 0.3）。
- **N5 先手与爆发正相关**：爆发/控制队（中军衔接位）加点倾斜速度（attack/speed 或 strategy/speed），抢先手放大爆发。
- **红度放大**：顶配 50级5红，把"强者愈强"的增伤/属性放大效应吃满（公平口径另附）。
- **阵位规律**：大营=队内第一胜负手、前锋=第一承伤者、中军=衔接，与①归类一致（见第三节）。
- **兵种克制 ±0.3 / 链路协同 / 同阵营加成 / 8回合上限→爆发+控制**：单阵营成队、增伤链+减伤控链+续航三链齐全，规避纯龟缩平局。
