## 战损口径（必读）

- 引擎逐将守恒：**初始 = 存活 + 终态伤兵 + 死兵**（已校验）。
- **战损(净) = 初始总兵 − 终态存活总兵 = 死兵 + 终态伤兵**：本场被消耗、不能立即再战的兵力。
- 拆分：**死兵**＝永久损失（需重新征兵）；**伤兵**＝可恢复（回城补满模型回复；野外连续作战持续衰减）。
- **胜场战损**：获胜时我方平均净兵损 —— 多穿/连续作战最关键的可持续指标（赢但打空血＝多穿黑洞）。
- **交换比**＝我方造成敌方平均净兵损 ÷ 我方平均净兵损（>1 表示我放血更多，越赚）。

- 全样本：17 队全双向 × 40 种子，T0 整体对 T1 胜率 9.6%（T1 反击 39.9%）。

- 多穿择优看「胜场战损 + 胜场死兵 + 交换比」三项，而非只看胜率。
