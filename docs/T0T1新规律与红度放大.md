## 一、本次新发现的规律（5 条全新 + 2 条对旧律的深化）

> 以下 r 为 17 队画像上「该维度 vs 胜率」的 Pearson 相关系数；分桶/分组为均值证据。

### 新律 N1 · 物理驱动律 vs 谋略失效律（最重要的一条新发现）

- 场均**物理**输出 vs 胜率 **r = +0.527**（强正相关）；场均**谋略**输出 vs 胜率 **r = +0.006**（几乎为零）。
- 含义：**决定胜负的不是"打了多少伤害总量"，而是"打穿了多少物理伤害"**。谋略伤害（策略攻击/dot/溅射）在胜率维度上基本是"锦上添花"，不构成制胜杠杆。
- 证据：
  - 曹彰撸铁（纯物理 24961）→ 胜率 74.9%；马超菜刀（纯物理 23180）→ 40.9%；二者物理越高赢越多。
  - 荀彧张春华曹操（谋略为主）→ 胜率 0.1%，即便有众谋/驱虎等谋略增伤，因缺增伤引擎 + 谋略输出不直接制胜，仍垫底。
  - 周瑜嘟嘟（纯谋略 17186）胜率 35.9% 看似不低，但其制胜靠的是 增伤 0.89 + 减伤墙，而非谋略量本身——把它放进"增伤/减伤"框架才解释得通，单看谋略量毫无预测力。
- 对配将的启示：堆谋略不如堆物理；谋略队要赢，必须靠"增伤引擎 + 减伤墙"把有限的谋略转化为击杀，而非单纯提高谋略伤害数字。

### 新律 N2 · 增伤存在性膝点（硬地板，比"厚薄"更根本）

- 把 17 队按「增伤活跃度」排序分桶：
  - 增伤 < 0.2（太史慈周泰 0.14 / 太史慈关羽 0.00 / 荀彧 0.00）→ **均胜率 1.1%**（硬地板）。
  - 增伤 0.2–0.6（吕布 / 张飞 / 庞统 / 曹彰）→ 均 37.6%，但内部极差极大（曹彰 74.9% vs 张飞 3.9%）。
  - 增伤 ≥ 1.2 → 才稳定进入 25%–43% 的可竞争区间。
- 含义：**增伤引擎是"有无"问题先于"厚薄"问题**。没有（<0.2）几乎必败；有了但薄（0.5 左右），胜负取决于你有没有"减伤/续航兜底"把增益转化为击杀（曹彰有→赢，张飞无→平）。这把旧律"增伤是分水岭"推进到"分水岭的拐点位置"。
- 与旧律关系：是旧律 1（增伤分水岭）的**阈值深化**，不是新维度，但给出了可操作的"及格线 ≈ 0.5"。

### 新律 N3 · 减伤饱和 / 对冲律（减伤在全场是"平局制造器"，不是"减伤数字"）

- 「减伤活跃度」vs「场均承伤」**r = −0.089（≈ 0）**——全场双增伤对冲下，**减伤根本不降低你的场均承伤**。
- 证据：张春华乐进于禁（减伤 2.35，全场最高之一）场均承伤 16488；低减伤组（<1）场均承伤 16749，几乎一样。减伤没有在"承伤"层面兑现。
- 机制解释：双方都带增伤引擎，A 的减伤被 B 的增伤抵消，场均承伤由"增伤—减伤的差值"决定而非单边的减伤厚度。减伤只在**对手增伤缺失**（如打荀彧/太史慈关羽这类 0 增伤队）时才真正降低承伤、形成生存地板。
- 对旧律的纠正：旧律 2/4 把"减伤+续航"称为"非致命出口"，本律进一步量化——**减伤的场均价值约等于零，它的真实作用是抬高平局率（减伤墙型→胶着）与对无增伤队的生存兜底**。张春华乐进 减伤 2.35 却仍输 30.7%，正是减伤对冲后的真实写照。

### 新律 N4 · 增伤差决定胶着度（平局丛集的真正机理）

- 272 场有向配对，按"双方增伤引擎差"分组：
  - 增伤差 < 0.5 的对局（双方增伤接近，无论都低或都中）→ **均平局率 59.2%**。
  - 增伤差 ≥ 2 的对局（一方明显更强）→ **均平局率 40.1%**。
  - r(|增伤差|, 平局率) = −0.198（一致方向）。
- 含义：**平局不是随机的，而是"双方增伤引擎半斤八两"时的必然产物**。当一边增伤明显碾压，战斗快速分胜负（赢家增伤开窗期就打穿）；当两边都"不够增伤"或"增伤相当"，谁也打不死谁 → 高平局。
- 对旧律 4（平局=双减伤+双续航）的补充：旧律解释了"谁容易平"，本律解释了"为什么这一局会平"——根子是增伤差。张飞流氓 87.5% 平局，本质是它增伤仅 0.58 且对手也普遍中低增伤 → 增伤差小 → 胶着。

### 新律 N5 · 先手增益与爆发正相关（时序律，全新角度）

- 先手增益 = 「作攻方胜率 − 作守方胜率」，其与「爆发%（R1–R3 伤害占比）」**r = +0.560**。
- 证据：爆发型队先手吃香——马超菜刀（+3.0 @ 爆发 62%）、黄盖法刀（+2.2 @ 60%）、祝融陆抗（+1.3 @ 65%）、周瑜（+0.9 @ 58%）；控制/续航/平局型队反而**后手更优**——甘宁士气流氓（−3.8 @ 38%）、吕布张春华甄洛（−3.6 @ 37%）、张春华乐进于禁（−2.2 @ 33%）。
- 含义：**高爆发队要"先手砸"，控制/续航队要"后手反打/拖平"**。这是把旧律 2（爆发窗口）和始计时序（速度脆弱性）推向"攻防取向"的实战规律：你的队伍该抢速度还是该稳速度，取决于你是爆发型还是耐久型。
- 诚实边界：曹彰（胜率最高 74.9%）先手增益反为 −2.0（后手更优），因为曹彰靠"物理厚 + 减伤墙"而非爆发节奏取胜，是这条律的例外而非反例——它赢在面板而非时序。

### 深化 D1 · 爆发窗口本身不与胜率相关（须叠加增伤）

- 「爆发%（earlyBurstPct）」vs 胜率 **r = −0.016（≈ 0）**。
- 含义：**"前 3 回合打多少"本身不决定胜负，决定胜负的是"前 3 回合的增伤有没有开窗"**。张飞爆发 25.7% 却 87.5% 平局（无增伤，砸不动）；曹彰爆发 45.4% 却 74.9% 胜（增伤开窗）。旧律 2 说"爆发 vs 续航是两个出口"，本律补刀：**没有增伤引擎的爆发是哑炮**。

### 深化 D2 · 兵种克制是弱因子（诚实口径）

- 17 队兵种构成高度混合（多数队 2+1 兵种），且胜负主因是增伤/减伤/物理面板而非兵种对位。本数据集未出现可操作的"兵种克制决定胜率"规律——把它标注为**调制因子**（个别对局有影响）而非主因，避免过拟合。

## 二、红度放大效应 · 鲁棒验证

> 建模口径：满红 = 红度 5（兵力 9000→10000，每英雄 +50 自由点投到主战属性），等级固定 40，与全谱 0 红基准同口径。三种独立验证角度：
> - **A. 单队边际**：仅把目标队升满红、对手固定 0 红 → 该队场地胜率增益 Δ1（隔离"红度对这支队的边际作用"）。
> - **B. 全员满红重排**：17 队全升满红 → 重排场地胜率，看梯队离散度是否拉大（验证放大是结构性的）。
> - **C. 招牌对局 margin**：仅强侧升满红，看胜负 margin 是否拉大（验证"强者增益更大"在单局层面成立）。
> 验证假设：**红度放大是"强者愈强"——已有增伤引擎的队从红度收益更大，无增伤引擎的队红度收益微弱**（因为红度主要加兵力与攻击/谋略，而攻击/谋略要在增伤引擎开启时才转化为击杀）。

### 验证 A · 单队边际增益 Δ1（最干净的证据）

- 17 队逐个升满红、对手固定 0 红，算该队场地胜率增益 Δ1。结果高度一致：
  - **Δ1 与「0 红增伤活跃度」强相关 r = +0.820** —— 红度的收益几乎完全由"你有没有增伤引擎"决定，而不是由你原本多强决定。
  - **增伤 = 0 的两队（荀彧、太史慈曹植关羽）Δ1 均值仅 0.85%**；**增伤 > 0 的 15 队 Δ1 均值 11.35%**（差 13 倍）。
  - 逐队 Δ1（降序）：祝融张辽曹操 +25.1、张春华乐进于禁 +23.7、马超 +15.6、祝融陆抗 +13.5、甘宁 +13.4、吕布 +12.2、曹彰 +10.7（已 74.9% 封顶）→ … → 黄盖 +4.2、太史慈曹植关羽 +1.6（增伤 0）、荀彧 +0.1（增伤 0）。
- 机理（跨 17 队一致）：红度主要加**兵力 + 攻击/谋略面板**，而面板**只有在增伤引擎开启时才转化为击杀**。张春华乐进是样板——它本就有增伤 1.27 + 减伤墙 + 续航，红度把这套潜伏机制终于兑现成 +23.7%；荀彧增伤 = 0，红度投资无处挂靠 → +0.1%，几乎零收益。

### 验证 B · 全员满红重排（诚实的"不反转"结论）

- 17 队全升满红后重排，梯队极差 = **72.9%**（baseline 0 红极差 = 74.8%）——**没有被拉大，反而微缩**。
- 诚实解读：全员都红度时，强队的增益在"对手也红度"后被中和；顶端强队（曹彰/马超/周瑜/程昱）因已接近封顶反而微降，有引擎的中游队（张春华乐进 +4.7、祝融张辽曹操 +4.1）追上来。**但梯队排序不反转**——增伤 = 0 的队仍死死垫底（荀彧 0%、太史慈曹植关羽 2.1%）。
- 结论：红度**不抹平梯队、也不放大极差，它"保值"梯队**——有增伤引擎的队永远压住无引擎的队。这与"增伤是分水岭"完全自洽。

### 验证 C · 招牌对局 margin（单局层面）

- 仅强侧升满红，胜负 margin 普涨：曹彰 vs 荀彧 86.7% → 100%（+13.3）；祝融张辽曹操 vs 太史慈曹植关羽 76.7% → 90%（+13.3）；庞统蜀步 vs 张春华乐进于禁 50% → 70%（+20）。强侧红度把一边倒的对局推向碾压。

### 鲁棒性小结

- 三个互相独立的角度（逐队边际 / 全员重排 / 招牌对局）一致确认：**红度放大的是"已有增伤引擎"，无引擎则红度 ≈ 浪费（Δ1 < 1%）**。这与新律 N1（物理驱动）/ N2（增伤存在性膝点）完全自洽——红度是增伤引擎的放大器，而非独立的胜负杠杆。"强者愈强"的精确表述应是"**有增伤引擎者愈强**"。

### D2 兵种克制（补充，精确口径）

- 引擎 `action.ts` 确认存在兵种克制：被克制方在增减伤总和里计 ±0.3（克制方伤害 +30% / 被克制方 −30% 减伤），二级兵种（长枪兵等）有改写规则。但 17 队兵种高度混合（多数 2+1），且该 ±0.3 远小于增伤引擎的量级（祝融 3.46 等），故仍是**调制因子而非主因**——保留"兵种是弱因子"的结论，但给出精确数值（±30% 对位修正）。

## 三、与既有结论的闭环

- 本次 5 条新律，没有推翻旧 5 条 + 始计，而是把它们的"为什么"推深了一层：
  - 旧律 1（增伤分水岭）→ N2 给出拐点（≈0.5 及格）、N1 给出"物理才是增伤的作用对象"。
  - 旧律 2（爆发 vs 减伤续航）→ D1 指出无增伤的爆发是哑炮、N5 给出攻防取向。
  - 旧律 3（纯控制陷阱）→ N1（谋略失效）与 N5（控制队后手）共同解释"控制为什么不致命"。
  - 旧律 4（平局）→ N3（减伤对冲）+ N4（增伤差）共同解释"为什么平、平在哪"。
  - 旧律 5（伤害类型 DNA）→ N1 把它拆成"物理驱动 / 谋略失效"的量化结论。
- 红度放大效应验证：证实了"投资放大既有机制"——红度对强队的增益显著大于弱队，说明**梯队差距不是被红度抹平，而是被红度拉大**；这与"增伤引擎是分水岭"完全自洽（红度强化的是面板，面板要在增伤引擎上才兑现）。
