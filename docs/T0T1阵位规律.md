# T0/T1 阵位规律：大营 / 中军 / 前锋是怎么定的

> 数据来源：`web/data/heroes.json`（四维+成长+攻击距离+主战法）、`web/data/opponent_benchmark.json`（T0 八队）、`docs/t0t1_roster.json`（T1 九队）。
> 阵位由阵容 `slots` 顺序决定：slot[0]=大营、slot[1]=中军、slot[2]=前锋（引擎 `buildTeam` 用 `RED_POSITIONS[i]`）。阵位**不是武将固有属性**，是装配决策，故本规律从"属性成长 + 攻击距离 + 主战法角色"反推。

## 一、主干规律（相对律）：阵位 = 相对队友的"胜负手权重" vs "承伤权重"

- **大营（后排·主心骨）**：全队"胜负手权重"最高者。条件：
  - ① 主战法含 **输出 / 控制 / 增伤** 中的胜负手效果（自身或敌军伤害结算）；
  - ② 攻击距离 ≥ 2（能从后排参与；若为直击敌方大营的单体需 ≥3）；
  - ③ 防御非全队最高（有更肉者挡前，自己需被保护）。
- **前锋（前排·盾+功能位）**：全队"承伤权重"最高者。条件（满足其一）：
  - ① 防御成长/肉度为全队最高；
  - ② 主战法为**抗压型**（自身减伤 / 规避 / 续航 / 反击 / 援护）；
  - ③ 攻击距离 = 1（只能打前排，必前排）；
  - ④ 纯谋略/法刀体系中作为"前排点火/控制位"（第二法师的体系特例，见第二节）。
- **中军（腰·衔接位）**：不满足大营（非核心胜负手或距离不足）且不满足前锋（非最肉/非抗压）的灵活位。主战法多为增益/控制/副输出/续航，起衔接放大作用；攻击距离 ≥ 2。

## 二、第二条律（体系特例）：同一英雄阵位随队友浮动

- **张春华**：有更大核心（吕布/太史慈/荀彧）时降 **中军**，自身即核心（张春华乐进于禁）时升 **大营**。
- **张辽**：缺肉盾（太史慈曹植张辽）时升 **前锋**（全队最肉），有曹操/赵云类肉盾时降 **中军**。
- **法刀/嘟嘟/魏智现象**：队内存在更纯粹的直伤胜负手（黄盖/王异/周瑜/程昱）时，高属性法师（吕蒙/郭嘉/陆逊）降位至 **中军/前锋**，充当"发动机"或"点火/控制位"，避免首轮集火、把被保护的大营留给直伤核。
- 结论：阵位是**相对**概念，不是英雄的绝对标签——先看"队里谁最能打、谁最能扛"，再排位置。

### 回判例外明细（6 个 · 全部属第二节相对律）

- **张春华乐进于禁**：规则按"输出权重"把物理增伤的乐进排大营，但实战以张春华「强势」（减伤48%+犹豫）为全队主控制锚点升大营、乐进降中军——同队存在更纯粹的控制/直伤锚点时，控制位即核心。
- **黄盖法刀**：规则按肉度把卫瓘「持节镇西」（全军增益/减伤buff）排大营，但实战黄盖「烈火焚舟」是直伤爆核、卫瓘被推前排承伤——法刀体系把buff位放前排、核藏大营。
- **程昱魏智**：规则按"输出"把荀彧排大营，但实战以程昱「审时定计」（敌受伤+30%+续航）为增伤胜负手升大营、荀彧降中军——魏智以增伤核而非控制核为锚。
- 共性：这三处的偏离都不是"规律错"，而是**同一英雄的阵位随队友的核心构成浮动**（第二条律），进一步印证"阵位是相对概念"。

## 四、三位置"优质"画像（打分口径，0–100）

### 优质前锋（承伤面 + 前排功能）
- 防御成长 ≥ 2.0（标杆曹操 2.95→满分），满级 DEF 高；
- 主战法自带**自身**抗压：减伤（周泰 84%、于禁 50%、曹操削敌属性+全军攻击距离）、规避/免伤（孙权）、援护、续航（甄洛/刘备）；
- 攻击距离 ≥ 2（能还手）；最好带反击/控制惩罚对手。
- 标杆：曹操（DEF成长2.95 + 全军减益光环）、周泰（84%减伤+援护）、赵云（DEF219+输出）、于禁（50%减伤）。

### 优质大营（胜负手 + 能覆盖敌阵）
- 攻击距离 ≥ 3（能打到敌方大营）；若为自身/友军增益或 AoE，距离2也可；
- 主战法是队内最高倍率/最稳的胜负手：物理看 ATK 成长 ≥ 2.0（吕布/祝融/甘宁/张飞/曹彰/马超），谋略看 STRAT 成长 ≥ 2.0（王异/程昱/庞统/周瑜）；
- 自身防御不垫底（有前锋扛伤），能吃到中军/前锋的保护增益。
- 标杆：马超(ATK305/距离3)、张飞(ATK307/距离2爆核)、周瑜(STRAT288/距离4)、庞统(STRAT282/距离3)。

### 优质中军（衔接 + 放大）
- 属性中庸但功能纯粹：增伤/控制/续航/副输出其一拉满；
- 攻击距离 ≥ 2–3，能稳定参与中距离交火；
- 能与大营形成联动：吕蒙（前2回合封普攻+延时策略爆发）、张机（减伤+续航）、曹植（减伤+续航）、司马炎（首回合减伤）。
- 标杆：吕蒙（规避+增伤+爆发发动机）、张机（减伤续航墙）、曹植（减伤续航）。
