- 测量口径：每支穿者(满兵满状态) 对 16 个对手各打 60 场首战，统计 **首战胜率 p1**（门槛）与 **胜场净损 effFull = 赢了之后还剩多少兵（死兵+终态伤兵均值，省兵效率核心代理）**；场均总损(含败)仅作参考，避免与效率混淆。

## 一、为什么用消融法（方法论与可信度）

上一轮已锁定多穿的两因子恒等式：**多穿资本 = 首战胜率(门槛) × 满兵胜场净消耗(效率)**。
本报告的任务是把这两个因子**归因到「战法 / 英雄属性」层面**，回答"怎样造出多穿队伍"。

方法——**消融实验(ablation)**：固定对手池，保持其他一切不变，只动一个要素（摘一个战法 / 错配加点 / 换位），
看 p1 与 avgNet 的变化量 Δ。Δ 就是该要素对"能赢"和"省兵"的**量化边际贡献**，避免了"看胜率猜原因"的定性陷阱。

- **门槛因子 p1**：Δp1 显著为负的要素 = 造门槛的核心（摘掉就赢不动）；
- **省兵因子 effFull（胜场净损）**：ΔeffFull 显著为正的要素 = 护省兵的核心（摘掉就大出血）。
- 对照 **E5 引擎实测权威因子排名**（战法 33.5% > 加点 12.9% > 站位 8.7% > 宝物 7.8% > 速度 4.7% > 红度 2.0% > 战法顺序/兵种/特性 ≈0）：本实验的消融 Δ 正是把"战法 33.5%"这一最大头**拆开到具体哪个战法**。

## 四、维度归因：哪些"机制维度"造就多穿（按 E5 框架拆解）

把每个战法按其在引擎中的效果标签归类到六大维度，再结合消融 Δ 判断该维度"主要贡献门槛还是省兵"。

| 维度 | 在多穿中的作用 | 典型战法(本样本) | 证据(消融) |
| --- | --- | --- | --- |
| 增伤链(增伤/攻击buff) | 决定"打不打得动"→ 门槛；高增伤缩短回合数→ 间接省兵 | 神赏天降、大赏三军、攻其不备、愈战愈勇 | 见各队"摘携带增伤战法"Δp1 |
| 减伤/护盾 | 直接压低场均净损 → 省兵核心；是真实多穿(不回城)的护城河 | 避其锐气、单骑救主、全军突击、重整旗鼓(减伤态) | 摘减伤战法 Δ场均净损最大 |
| 爆发窗口(前3回合/准备) | 速杀压低回合数 → 省兵；但准备期怕控 | 神兵天降、法系爆发、菜刀 | 高爆发队场均净损偏低但门槛看增伤厚度 |
| 控制(犹豫/怯战/围困/混乱/恐慌) | 剥夺敌方行动 → 变相增伤+省兵(敌方不反击) | 浑水摸鱼、妖术、反间、当阳桥 | 摘控制战法常伴随 Δp1 与 Δ场均净损双降 |
| 续航(回复/重整/恢复士气) | 把"伤兵"变回"兵力" → 省兵+对补给不敏感 | 重整旗鼓、步步为营、皇裔流离、桃园结义 | 摘续航战法 Δ场均净损显著为正 |
| 发动率 | 决定战法稳定性 → 门槛下限 | 低发动率主动战法 | 触发率<1 的主动战法波动更大 |

**核心论证**：增伤/爆发/控制 **主要造门槛**（决定"赢不赢第一场"），减伤/续航 **主要造省兵**（决定"赢了还剩多少"）。
这正是上一轮"多穿 = 门槛 × 效率"在战法层的投影——增伤维度喂门槛，减伤/续航维度喂效率。

## 六、量化造队指南（从数据提炼）

基于 9 队消融 Δ，给出"造一支多穿队"的可操作优先级（按对两因子的边际贡献）：

1. **先保门槛（伤害控制能力 = 增伤链厚度 + 控制）**：主战法随英雄绑定（不可剥离，是英雄身份本身，不是可决策项）；门槛的**可决策**部分来自携带的「神赏/大赏类增伤指挥 + 增伤/追击战法 + 控制战法」。摘核心携带增伤/控制战法对 p1 的 Δ 最大，证明携带战法才是你"配将"能决定的门槛基座。
2. **再压省兵（减伤/续航）**：在能赢的前提下，队里必须有至少 1 个减伤/护盾 + 1 个续航战法。摘减伤/续航战法通常使 Δ胜场净损 大幅为正（最护省兵维度）。这是"不回城也能穿"的关键（上一轮 Law C）。
3. **加点/站位不可错配**：错配加点(攻/谋互换) 与 大营↔前锋换位 会同时吃掉 p1 与省兵，属"基础正确性"，不是增益来源。
4. **红度/宝物是放大而非分化**：满红让 p1 与省兵同步 +，但不改变谁更擅多穿。预算有限时，优先把核心战法（增伤/减伤/续航）配齐，再谈红度。
5. **流派启示**：血赚型(庞统蜀步) = 主战法增伤够厚 + 双减伤续航；惨胜型(曹彰撸铁) = 增伤极厚(门槛高) 但缺续航(费兵)。造队应追求前者形态。

## 七、结论（多穿本质的战法级回答）

1. **门槛由"伤害控制能力"造就**：主战法随英雄绑定（不可剥离=英雄身份），门槛的可决策部分 = 携带的增伤指挥/追击战法 + 控制战法，决定"第一场打不打得动"，摘核心携带增伤/控制战法对 p1 的 Δ 最大。
2. **省兵由"减伤/续航维度"造就**：减伤护盾 + 回复/重整直接压低场均净损，摘之则大幅费兵；这是真实多穿(不回城)的护城河。
3. **战法搭配 > 单卡强度**：同一英雄，携带什么战法决定了它喂门槛还是喂省兵；错配加点/站位是纯损耗。
4. **红度/宝物是放大系数**：满红普惠提升两因子但不改变排序（E5 红度仅 2.0%）。
5. **造队公式**：伤害控制能力(门槛) × 续航/减伤/速杀(省兵能走多远) × 正确加点站位 = 多穿队；优先血赚型（高门槛 + 低耗），避免高增伤无续航的惨胜型。

**一句话**：多穿的"能打"来自伤害控制能力（主战法随英雄走不可剥离 + 携带增伤/控制战法），"省兵走多远"来自续航 > 减伤 > 爆发速杀；
两者齐备且加点站位正确，再用红度/宝物放大——这就是"怎样造就多穿队伍"的量化答案。
