## 〇、方法与口径（本篇相对前作的两条关键升级）

- 全循环规模
  - 17 队（8 T0 + 9 T1）全双向循环：272 组有向配对 × 40 种子 = **10880 场**，每场用 `runBattle` 跑满 8 回合。
  - 每个有向配对输出**均值**胜平负率 / 场均伤 / 物理·谋略 / 爆发% / 增伤活跃度 / 减伤活跃度 / 控制 / 续航 → 单局随机被平均掉。
- 单位 id 修正（重要）
  - 之前 reports/crosssim 用未加前缀的 heroId 作 `selfIds`，当**同一英雄跨队重复出场**（曹操/张辽/吕蒙/张春华/荀彧等）时，双方伤害与增伤会被**错算到一边**。
  - 本篇给双方单位加 `A:` / `B:` 前缀（`g.id = side + ':' + g.id`），引擎事件自动带上前缀，`sideStats` 可正确分离同英雄跨边。原 7 份单局战报里涉及"曹操 vs 曹操"等配对的数字有轻微污染，本篇均值更干净。
- 战法覆盖口径
  - 全 80 个不重复战法（33 主战法 + 47 携带战法）中，**贪心最小覆盖**选出的 9 场战斗已使**全部 80 战法至少上场一次**（含 2 个被动战法「先驱突击 / 青囊秘要」——它们不产生 `skill_trigger` 事件，但英雄上场即生效，故按"携带即上场"计入）。9 场同时覆盖**全部 17 队**。
  - 多出 2 个引擎内部技能（普攻/反击类）不在 80 之列，不影响覆盖。

## 二、用均值数据反向验证 5 条底层定律 + 始计时序结论

### 定律 1 · 增伤引擎是 T0/T1 真正分水岭（均值视角最干净）
- 增伤 = 0 的两队（荀彧 0.1%、太史慈关羽 1.3%）稳居最后两名；增伤 0.14 的太史慈周泰（2.0%）倒数第三。
- 增伤 > 0 的 12 队全部排在它们前面。
- 唯一"增伤不高却夺冠"的曹彰（增伤 0.59）：靠**纯物理 brute force（物理 24961，全场最高）+ 减伤 1.29** 兜底，属于"增伤×减伤×高输出"三件套里的后两件补足——本质上仍不违背定律，而是定律的"替代出口"变体。
- **结论**：增伤 = 0 足以判定一支队掉到底部；增伤 > 0 是脱离底部的必要条件（非充分，还需减伤/输出配合）。

### 定律 2 · 爆发窗口 vs 减伤+续航，是把增伤转化为胜率的两个出口
- 庞统蜀步（增伤仅 0.58，但**减伤 1.71 + 续航 10561**，全场最厚墙）→ 46% 胜、第 2 名。说明**足够厚的减伤续航墙本身就是赢法**。
- 张春华乐进于禁（增伤 1.27、**减伤 2.35** 也很厚、续航 5993）→ 却只有 15.5% 胜。差别在：庞统有 8694 谋略输出能真正收人头，张春华乐进的增伤没转化成足够击杀（承伤 16488 偏高、输出被稀释）。
- 祝融张辽曹操（增伤 3.46 全场最厚，但减伤 0.54、续航 0）→ 42.6% 胜，靠爆发碾压但被反伤时也脆。
- **结论**：增伤是"因"，爆发或减伤墙是"果"的两个出口；只有增伤、没有出口的队（增伤不转化）仍输——张春华乐进即此。

### 定律 3 · 纯控制 / 缺增伤是非致命陷阱
- 控制次数最高的两队：张春华乐进于禁（16.6）、吕布张春华甄洛（13.1）→ 胜率分别只有 15.5% / 25.5%。
- 控制造的是"输出窗口"而非"杀伤"。底部 5 队里荀彧/太史慈关羽增伤 = 0，纵有控制（8.3 / 4.9）也造不出伤害 → 垫底。
- **结论**：控制 rank 与胜率 rank 几乎无关；增伤才是 divider。

### 定律 4 · 平局 = 8 回合上限 + 双方同存活
- 平局率最高：张飞流氓 **87.5%**、黄盖法刀 73%、王异法刀 73%、吕布 66.8%、荀彧 75.4%、太史慈周泰 60.2%。
- 张飞流氓画像：减伤 1.07 + 续航 7692 + 爆发仅 25.7 + 增伤 0.58 → **既打不死人、也难被打死**，典型"平局制造机"。
- 减伤墙型（庞统 41.5%、张春华乐进 53.8%）也高平局：墙太厚、8 回合打不穿。
- **结论**：平局是"双方都没在 8 回合内消灭对方"的副产品，与增伤厚度负相关（增伤越厚越容易在 8 回合内结束战斗）。

### 定律 5 · 伤害类型揭示流派 DNA（均值视角更分明）
- 纯物理队：曹彰（物理 24961/谋略 1394）、马超（23180/0）、甘宁（15255/4853）、张飞（18094/0）、太史慈曹植张辽（12582/774）。
- 纯谋略队：周瑜（4397/17186）、程昱（3283/16074）、王异（5257/11066）、黄盖（4900/12166）。
- 混合队：庞统（11144/8694）。
- 物理/谋略占比在均值下几乎"非 0 即满"，流派 DNA 一眼可辨，且决定它们各自怕什么（物理队怕减伤墙、谋略队怕谋略减伤/洞察）。

### 始计时序结论（v2 硬编码）在全谱的复现
- 吕布张春华甄洛（增伤 0.45）：深读 #1、#9 中张春华「始计」R1 接通（张春华基准速度 156 > 吕布 132），吕布伤害带 `damage_boost`，始计确实接到大营。
- 太史慈张春华周泰（增伤 0.14）：深读 #5 中太史慈带「先驱突击·优先行动」强制先动，把张春华始计顶到 R1 之后 → R1 始计 0% 接通，整队增伤几乎为空，被曹彰 R5 全灭。
- 荀彧张春华曹操 / 太史慈曹植关羽（增伤 0）：根本无增伤引擎，深读 #6、#8 复现其"高非败、零胜率"的乌龟形态。
- **结论**：始计的"接通"依赖"张春华快于大营且无优先行动顶位"，在全谱里稳定成立。

## 三、诚实口径（必须说清的两件事）

- **全循环压缩效应**：每队打全 16 对手，遇到强队必输、遇到弱队才赢，所以连曹彰也只有 74.9%、连祝融也才 42.6%。这里的"胜率"是"对全谱的均势度"，**不是单挑强度**。要测单挑强度看配对矩阵（`pairs` 字段）。
- **增伤维度 > 梯队标签**：
  - 曹彰（T1，74.9%）> 祝融（T0，42.6%）> 大多数 T0；
  - 太史慈关羽（T0，1.3%）/ 荀彧（T0，0.1%）< 许多 T1。
  - 8 支内置 T0 基准内部极差极大（0.1% ~ 42.6%），说明"T0"是制作人测试集、并非真实强度排序。**真正区分强弱的是增伤引擎的"有无 + 厚度 + 时序接通 + 减伤兜底"，不是标签。**

## 四、9 场深读战报（覆盖全 80 战法 + 全 17 队）

> 说明：深读场为"覆盖全部 80 战法"的**最少场次**（贪心最小覆盖），并非按胜负代表性挑选；其单局结果可能含种子随机（见各场备注），**权威胜率证据看第一节均值画像**，深读用于"看见机制"。

- **#1 吕布张春华甄洛【T0】 vs 太史慈曹植关羽【T0】｜胜 R6**

  - 印证：定律 1（增伤 0 的 T0 被增伤在线的 T0 碾压）。

- **#2 黄盖法刀【T1】 vs 庞统蜀步【T1】｜平 R8**
  - 机制：庞统侧减伤 1.71 + 续航 10561 的厚墙，黄盖法刀（谋略爆发）8 回合打不穿；末兵 A=[1800,3248,0] B=[8189,7392,8248]。
  - 印证：定律 2（减伤墙型赢法）+ 定律 4（墙太厚→平局）。

- **#3 张春华乐进于禁【T0】 vs 张飞流氓【T1】｜平 R8**
  - 机制：双方都是"减伤+续航拖局"形态（A 减伤 2.35 续 5993 / B 减伤 1.07 续 7692），8 回合双存活。
  - 印证：定律 4（平局制造机），也见定律 2 的"减伤墙但缺击杀→平局"。

- **#4 祝融张辽曹操【T0】 vs 程昱魏智【T1】｜平 R8**
  - 机制：祝融增伤 3.46（全谱最厚）却被程昱的减伤 0.38 + 荀彧大赏 + 谋略输出墙拖住，8 回合未收尾。本场是**种子随机**典型——均值下祝融 42.6% ≫ 程昱 25.9%，此 seed 恰平。
  - 印证：定律 2（增厚减伤可扛爆发）+ 说明"为何要均值"。

- **#5 太史慈张春华周泰【T0】 vs 曹彰撸铁【T1】｜负 R5**
  - 机制：太史慈先驱突击顶掉张春华始计（R1 始计 0% 接通），全队增伤 0.14，被曹彰纯物理 brute force（物理 24961）R5 全灭。
  - 印证：始计时序结论 + 定律 1（增伤≈0 的 T0 被强物理 T1 碾压）。

- **#6 祝融陆抗曹操【T0】 vs 荀彧张春华曹操【T0】｜平 R8**
  - 机制：祝融侧增伤 1.77 但仍被荀彧侧的减伤 0.32 + 续航 + 曹操同英雄对冲拖住；单 seed 平局，均值下祝融 14.4% ≫ 荀彧 0.1%。
  - 印证：定律 1（增伤 0 的荀彧队纵有曹操也难赢）+ 说明"为何要均值"。

- **#7 甘宁士气流氓【T1】 vs 周瑜嘟嘟【T1】｜胜 R7**
  - 机制：甘宁增伤 1.22 + 减伤 1.61 + 续航 3518，对周瑜（增伤 0.89、减伤 0.38、续航 0 的脆皮纯谋略）形成"增伤+减伤双保险"压制。

- **#8 太史慈曹植张辽【T0】 vs 王异法刀【T1】｜平 R8**

## 五、最终回答「为什么是 T0 / 为什么是 T1」（全谱均值版）

- **共同根因不变**：增伤引擎的「有无 / 厚度 / 开窗位置 / 时序接通」仍是全部规律的根。均值下底部 5 队增伤全部 ≤ 0.61、增伤 = 0 的两队垫底，是最干净的铁证。
- **T0 标签的真相**：8 支内置 T0 基准内部极差 0.1%~42.6%，其中增伤 = 0 的（荀彧/太史慈关羽/太史慈周泰）实际弱于多数 T1；增伤在线的（祝融 42.6%）才配得上 T0 之名。
- **T1 里能打过 T0 的**：曹彰（增伤 0.59 + 物理 brute + 减伤墙，74.9%）、庞统（减伤墙 + 谋略输出，46%）、甘宁（增伤×减伤双保险，43.3%）——它们不是"侥幸"，而是增伤+减伤/输出三件套齐全。
- **一句话定律**：**有无增伤引擎决定你是否在底部；增伤 ×（爆发窗口 | 减伤续航兜底）的乘积决定你能爬多高；控制、减伤、续航都是放大器或替代出口，但谁也替代不了增伤引擎本身。**
