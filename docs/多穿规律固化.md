# 多穿规律固化（权威版）

> 来源：`scripts/t0t1_duochuan.mts`（宏观两因子）× `scripts/t0t1_duochuan_deep.mts`（战法级消融）。
> 配套数据：`docs/t0t1_duochuan_deep.json`（9 队 × 逐项消融 Δ）、`docs/t0t1_duochuan_deep.md`（每队档案 + 消融表）。
> 运行：`SEEDS=60 npx tsx scripts/t0t1_duochuan_deep.mts`（约 13 分钟 / 11 万场）。

## 方法论底座（含纠偏）

- **主战法随英雄走，不可剥离**：主战法是英雄身份的一部分，不属于"配将"的可决策项。**任何"摘除主战法"的实验都是伪实验**，已从消融中剔除。
- **可决策的"配将"部分 = 携带战法**：你真正能选、能决定队伍上限的是每个英雄的 2 个携带战法。
- 两因子框架（已校验）：**多穿 = 首战胜率(门槛) × 满兵胜场净消耗(省兵效率)**。
  - 控制首战胜率后，effFull 与穿数 Spearman = **−0.633**（省兵决定"赢后走多远"）；未控制时 ≈0（效率信号被胜率掩盖）。
  - 首战胜率本身与穿数 Spearman = **1.0**（赢不下第一场就穿不动）。

---

## 第一点（描述）：多穿 = 伤害控制能力（门槛）× 续航减伤（能走多远）

- **门槛 = 伤害控制能力**：第一场"打得动、压得住"的硬条件。
  - 由 **主战法（英雄绑定，不可剥离）** 提供基座，由 **携带的增伤指挥/追击战法 + 控制战法** 提供可决策的厚度。
  - 控制战法（犹豫/怯战/围困/恐慌等）剥夺敌方行动 = 变相增伤 + 减伤（敌方不反击），是"伤害控制能力"的关键组成。
- **省兵续航减伤 = 能走多远**：赢了第一场之后，还能剩多少兵继续穿下一场。
  - 由 **续航（回复/重整/治疗）／减伤护盾／爆发速杀（缩短回合）** 决定。续航与减伤把"伤兵"压住、把"死兵"压住，使不回城也能滚雪球。
- **一句话描述**：多穿的本质不是"能打"，而是"先用伤害控制能力赢下第一场（门票），再用续航/减伤把省下的兵滚进下一场（走多远）"。

---

## 第二点：特定英雄必须有必备战法（携带战法不可替换，主战法随英雄走）

- **定律**：每个核心英雄的 2 个携带战法中，往往有 1 个是"必备、不可替换"的——摘掉它，首战胜率 p1 暴跌，整队崩盘。
- **证据（消融：摘掉某携带战法对 p1 的跌幅 = 该战法的必备度）**：

  | 队伍 | 必备携带战法（摘掉即崩） | 首战胜率 p1（摘掉前 → 后） | 崩幅 |
  | --- | --- | --- | --- |
  | 甘宁士气流氓 | 甘宁·汜水关 | 43% → 5% | **−38%** |
  | 马超菜刀 | 马超·一骑当千 | 40% → 2% | **−38%** |
  | 曹彰撸铁 | 曹彰·一骑当千 | 72% → 37% | **−35%** |
  | 敌方·吕布队 | 吕布·汜水关 | 27% → 11% | −16% |
  | 周瑜嘟嘟 | 吕蒙·河内世泽（法刀增伤指挥） | 41% → 24% | −17% |
  | 庞统蜀步 | 庞统·楚歌四起 | 45% → 32% | −13% |
  | 王异法刀 | 吕蒙·道行险阻 | 9% → 2% | −7%（低门槛，噪声） |
  | 黄盖法刀 | 吕蒙·道行险阻 | 8% → 0% | −8%（低门槛，噪声） |
  | 张飞流氓 | 张飞·一骑当千 | 4% → 0% | −4%（噪声，不参与定律） |

  > 数值来自 `t0t1_duochuan_deep` 消融实验（SEEDS=60，每配置 960 场，已独立复算确认非噪声）。完整逐项 Δ 见配套报告与各队档案。低门槛队（p1<15%）胜场极少，其 Δ 为噪声，已剔除出定律归纳。

- **推论**：高门槛 ≠ 稳健门槛。靠单点携带战法堆到极致的队（甘宁/马超/曹彰），该战法一旦不发动或被压制即整队崩 → 接第三点。

## 第三点：单点脆弱性 + 必须有冗余第二来源

- **单点脆弱性**：当核心输出/增伤只压在一个携带战法上时，该点失效 = 整队崩盘。
  - 例（最终 SEEDS=60 数据）：甘宁摘掉汜水关 p1 43%→5%（−38%）、马超摘掉一骑当千 40%→2%（−38%）、曹彰摘掉一骑当千 72%→37%（−35%）——这些队靠单携带战法撑门面，一旦该战法不发动或被压制即整队崩。
  - 注：主战法随英雄绑定不可剥离，是"门槛基座"（英雄身份本身），不计入脆弱性消融；脆弱性指的是**可决策的携带战法**不可单点依赖。
- **冗余第二来源（稳健门槛的充要条件）**：核心输出/增伤至少有"第二来源"——
  - 双输出将（如法刀双核：吕蒙 + 周瑜/王异/黄盖互相兜底，任一不发动仍有另一核）；
  - 或主战法之外还有**覆盖全队的增伤指挥**（神赏/大赏类）做保底。
- **结论**：多穿稳定性 = 门槛厚度 ×（核心点是否冗余）。单点堆到极致的"脆门槛"看似强（曹彰 p1 最高），实战最易翻车；双支点队（庞统：主战法增伤 + 刘备减伤续航）更稳。

---

## 第四点：省兵优先级 续航 > 减伤 > 爆发速杀；红度/宝物只放大不分化

- **省兵的三类驱动（按"摘掉它赢一场多花多少兵"的护省兵强度；最终 SEEDS=60 数据）**：

  | 驱动维度 | 机制 | 代表携带战法（摘掉 Δeff，本样本） | 省兵强度 |
  | --- | --- | --- | --- |
  | **减伤 / 速杀** | 压低每回合受伤 + 缩短回合（减少伤兵衰减利息） | 道行险阻（黄盖队吕蒙 +3786、王异队吕蒙 +1117）、战必断金（吕布队甄洛 +3608） | 最强可携带杠杆 |
  | **续航** | 把伤兵变回兵力，直接压场均净损；对补给最不敏感 | 三军之众（甘宁队孙权 +2924）、兵无常势（庞统队刘备 +1174） | 强（机制最直接） |
  | **控制** | 剥夺敌方行动 = 变相减伤（敌方不反击） | 反计之策（马超队张辽 +1864）、浑水摸鱼（曹彰队木鹿 +2106）、河内世泽（周瑜队吕蒙 +727） | 中 |

  > **省兵优先级（设计原则）：续航 > 减伤 > 爆发速杀**。机制上续航最"直接"（伤兵→兵力，且对补给最不敏感）；数据印证：续航类最护省兵的个案是**皇裔流离（刘备主战法，历史含主战法口径测得 +6620，为全样本最大省兵贡献）**——它随英雄常驻不可剥离，本身就证明续航是最强省兵维度。在**可自由携带**的战法里，减伤/速杀（道行 +3786、战必 +3608）与续航（三军 +2924）并列主力，控制类次之。整体与"续航 > 减伤 > 速杀"一致：**优先给队伍配续航，其次减伤，最后用爆发速杀收尾**。这是"不回城也能穿"的护城河（上一轮 Law C：回城增益与 effFull 同向，低耗队不回城也能穿）。

- **红度 / 宝物 = 放大系数，不是分化系数**：
  - 满红（50 级红 5）让 p1 与省兵同步 +11%~19%，但**不改变队间排序**（呼应 E5 因子排名：红度仅 2.0%、宝物 6.7%）。
  - **预算优先级**：先把核心战法（增伤 / 减伤 / 续航）配齐，再谈红度。红度救不了一支战法搭配错的队。

## 造队操作清单（量化落地）

1. **选英雄**：主战法即门槛基座，随英雄走、不可改——选将本质是在选"门槛基座"。
2. **配携带（必备战法）**：每个核心英雄的携带战法里，必须保留其"必备战法"（见第二点证据表）；增伤/控制喂门槛，续航/减伤喂省兵。
3. **做冗余**：核心输出/增伤至少有第二来源（双输出将 或 全队增伤指挥），避免单点脆弱。
4. **省兵优先级**：先堆续航，再堆减伤，最后用爆发速杀收尾（续航 > 减伤 > 速杀）。
5. **加点 / 站位正确**：错配加点（攻/谋互换）、大营↔前锋错位是纯损耗，同时吃掉 p1 与省兵。
6. **最后放大**：红度 / 宝物只在前面都做对后才有效，只放大不分化。

**终极一句话**：多穿 = 用"伤害控制能力"（主战法随英雄走不可剥离 + 携带增伤/控制战法）赢下第一场，再用"续航 > 减伤 > 爆发速杀"把省下的兵滚进下一场；核心战法配齐且冗余，红度只做放大。
