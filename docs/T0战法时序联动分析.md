## 〇、口径与数据底座（先讲清，结论才有意义）

- 参战阵容
  - 仅 8 支内置 T0 基准队（用户指定「仅 T0 英雄深读」）；对手为全 16 队（含 9 支 T1）仅作节拍对照，不深读其战法。
  - 队伍：`bench-lvbu-zhangchunhua-zhenluo`(吕布张春华甄洛)、`bench-zhangchunhua-yuejin-yujin`(张春华乐进于禁)、`bench-taishici-caozhi-zhangliao`(太史慈曹植张辽)、`bench-zhurong-zhangliao-caocao`(祝融张辽曹操)、`bench-taishici-zhangchunhua-zhoutai`(太史慈张春华周泰)、`bench-taishici-caozhi-guanyu`(太史慈曹植关羽)、`bench-zhurong-lukang-caocao`(祝融陆抗曹操)、`bench-xunyu-zhangchunhua-caocao`(荀彧张春华曹操)。
- 公平性归一（与混战论证一致）：全队 **40 级 · 0 红 · 士气 120 · 无宝物**，隔离投资差，只看流派机制。
- 时序抽取口径
  - 每支 T0 队作为**攻方** vs 全 16 对手 × **80 种子** = 1280 场／队，共 10240 场（v2 由 20 种子升级，关键数值波动 <3%，结论更稳）。
  - 逐场从 `BattleReport.events` 抽：每回合「增伤活跃度 / 减伤活跃度 / 控制次数 / 伤害输出 / 续航恢复」+ 每个战法的「首次激活回合分布」与「各回合触发次数」。
- 回合内行动顺序精拆口径（始计接通验证，v2 新增）
  - 仅含「始计(shiji)」的 2 支 T0 队（吕布张春华甄洛、太史慈张春华周泰）作为攻方，vs 全 16 对手 × 80 种子 = 1280 场／队，共 2560 场。
  - 逐场重建回合内事件顺序，双保险判定：① 修饰铁证——大营每次伤害事件的 `modifiers.caused` 是否含 `skillId=shiji`（含→吃到 +20%~+30%）；② 顺序解释——同回合内 张春华的 shiji 触发是否早于大营首次攻击。
- 指标语义（务必看清，避免误读）
  - **增伤活跃度曲线**：每回合我方造成伤害时，当场生效的增伤幅度之和（神兵天降 / 大赏三军 / 攻其不备 / 始计 等的 caused＋taken 归因），按「该回合仍在进行」的场次数平均 → 反映增伤「何时开、多厚、何时关」的**相对强度时间序列**（不是混战论证里按全场累计的「增伤链百分比」）。两者方向一致、量纲不同，下文交叉引用。
  - **减伤活跃度 / 控制 / 伤害输出 / 续航** 曲线同理逐回合。
  - **准备战法**：描述含「准备」二字的战法（浑水摸鱼、奇术折冲、三术奇谋、焰焚箕轸）→ 引擎在 R1 起手准备、R2 结算生效，故其**控制效果实际落 R2**（首次激活众数虽是 R1，那是「起手准备」回合）。
  - **瞬发战法**（始计、战必断金、大赏三军、其疾如风、强势、落雷等）→ R1 即生效。

## 二、逐队时序联动图谱（按增伤引擎强弱排序）

> 排序依据：增伤活跃度曲线厚度（与混战论证增伤链方向一致）。从「增伤恒 0」到「增伤极厚」，正好复证分水岭定律。

- 祝融夫人张辽曹操 [增伤极厚 + 前压对齐爆发]（增伤活跃度 6.5→7.0→6.5→2.1…）
  - 增伤开窗：R1–R3 极厚（6.5/7.0/6.5），R4 断崖至 2.1。
  - 爆发窗口：伤害输出 R1 6169 → R2 6022 → R3 5323 → R4 2346（R1–R3 即打完全部输出的 70%+）。
  - **联动诊断**：增伤开窗（R1–R3）= 爆发窗口（R1–R3），完美对齐。机制根因：R1 同时开启「其疾如风（双次普攻＋速度+41）× 大赏三军（全军+30%）× 长兵/并进（分兵）× 火兽冲锋（自身增伤叠加）」→ 乘法叠乘，R1–R3 增伤爆炸式累积，正是混战论证里增伤链 2744% 的时序来源。
  - 减伤：R1–R3 仅 0.9/0.9/0.8（薄），靠「先手增伤＋分兵速杀」而不是靠肉；承伤 R3 2976 可控。
  - 控制：仅 R2 起 浑水混乱 0.6（薄），不依赖控制——增伤＋爆发已够杀死对手。
  - 结论：教科书级「增伤引擎 × 爆发窗口」时序闭环，所以 8 队里胜率最高。

- 祝融夫人陆抗曹操 [增伤中厚 + 前压，但缺全队大赏]（增伤活跃度 2.9→2.6→3.0→1.3…）
  - 增伤开窗：R1–R3 中厚（无曹操大赏，只有祝融自身火兽冲锋增伤＋长兵分兵），峰值 R3 = 3.0。
  - 爆发窗口：伤害 R1 4444 → R3 3726 → R4 1860；与增伤开窗对齐。
  - 减伤：R1–R3 1.2/1.7/1.8（避其锋芒 R1–R3 我军受击-30%＋战必怯战），比祝融张辽曹操厚。
  - 控制：R1–R3 怯战 1.9（战必断金瞬发）。
  - **联动诊断**：增伤厚度只有祝融张辽曹操的约 40%（缺曹操大赏三军全队增伤），所以胜率 15.2% 远低于前者 42%——同一祝融核心，有没有「全队大赏」这一环，时序增伤厚度差一倍，梯队差一档。

- 张春华乐进于禁 [增伤后发 R5 + 减伤持续 + 自愈]（增伤活跃度 0.5→1.2→1.3→1.5→1.7→1.8→1.8→1.7）
  - 增伤开窗：**后发**，R5–R7 达峰（1.8）。机制：乐进 奋疾先登 每回合自身攻伤+8%（叠到 40% 触发距离3群体攻190%）、愈战愈勇 每回合+10%。
  - 爆发窗口：伤害 **单调上升** R1 1449 → R5 3095 → R8 3084（典型后发队）。
  - 减伤：R1 2.6 → R8 1.8（步步为营/当敌制决/百战无怯 叠加，持续不衰减）——全 8 队里减伤最持久。
  - 承伤：R2–R3 爆炸（4528/4253）后 **R8 塌到 925**，说明减伤/自愈随回合发力把对手磨干。
  - 续航：R1 即 1083（百战无怯/以诱待来受击恢复），高峰 R1。
  - **联动诊断**：增伤引擎「启动太慢」（R5 才达峰），而战斗只有 8 回合上限——很多局增伤还没充分兑现就到 R8，导致 **平局率 52.7%**（混战论证）。这是「有增伤但缺爆发窗口」的另一种失败形态：链存在，但太长。

- 太史慈曹植张辽 [增伤开窗 R1–R3 但减伤缺失 → R3 被反杀]（增伤活跃度 1.5→1.6→1.6→0.1…）
  - 增伤开窗：R1–R3 厚（大赏三军+30%＋其疾如风双次普攻），R4 断崖至 0.1。
  - 爆发窗口：伤害 R1–R3 2746/2515/2696，R4 崩到 1272——增伤开窗和输出前压都对。
  - **致命断裂点**：承伤 R3 **爆炸到 4265**（全队第二高），减伤仅 0.4–0.6（薄）。增伤窗口（R1–R3）正好和敌方爆发窗口（R3）正撞，而我方减伤兜底缺失 → 增伤还没充分兑现就被打崩。
  - 控制：仅 0.7–0.9（薄，只有曹植落雷/迷阵）。
  - **联动诊断**：增伤引擎存在（大赏），但「减伤兜底」这一环断裂——印证混战定律「增伤 ×（爆发 或 减伤续航）」缺后者即不稳。胜率仅 6.2%、承伤 21714 最高。

- 吕布张春华甄洛 [增伤薄 + 控制减伤 + 续航拖型]（增伤活跃度 0.9→0.9→0.9→0.6→0.2…）
  - 增伤开窗：R1–R3 薄（0.9），R4 后归零。唯一增伤来源是 始计 给大营（吕布）下次攻击+20%（实测约+30%）——**只覆盖大营的「下一次攻击」单次**（R1 实测接通约 50%，见第四节），非速度失效。
  - 爆发窗口：伤害平铺 R1 2726 → R4 3147（无集中爆发）。
  - 控制：R1–R3 2.5/3.1/2.9（战必怯战＋强势犹豫＋浑水混乱 R2），全队第二高。
  - 减伤：薄（0.3–0.5）。续航：洛水佳人 R2 起 445 → R5 658（后发续航）。
  - **联动诊断**：这是「控制 + 减伤 + 续航」拖型，不靠增伤。非败 91.6% 但胜率仅 25.8%——始计的薄增伤没形成爆发。始计的脆弱性见第四节。

- 太史慈张春华周泰 [增伤极薄 + 减伤前重后轻]（增伤活跃度 0.1→0.3→0.3→0.3→0.1…）
  - 增伤开窗：极薄（始计给太史慈/周泰下次攻击+20%，峰值仅 0.3；且太史慈带先驱突击优先行动，R1 始计 0% 接通，见第四节）。
  - 减伤：R1 **3.4**（周泰疮痍累身-84% 前重）但 **衰减到 R8 0.8**（疮痍每受击降 1/12）。
  - 承伤：R3 **4011** 仍高（减伤衰减＋周泰前锋吃伤）。
  - **联动诊断**：增伤薄（始计小增伤）＋减伤「前重后轻」（R1 猛 R8 弱）→ 后期承伤失控。胜率 2.6%。

- 荀彧张春华曹操 [增伤恒 0 + 控制最高 + 减伤薄]（增伤活跃度 全 0）
  - 增伤开窗：**整场恒 0**。荀彧三战法（驱虎吞狼/众谋不懈/激水之疾）全是直接伤害/控制，**没有任何增伤 buff 类**；曹操 共饮避世 是减伤非增伤。
  - 控制：R1–R3 **2.6/2.8/2.5（全 8 队最高）**（战必怯战＋强势犹豫＋落雷混乱）。
  - 减伤：薄（0.3–0.5）。续航：薄（R5 239）。
  - **联动诊断**：铁证级「纯控制/减伤乌龟」——控制最高却增伤为零，非败 75.6% 但胜率 0.2%（混战论证）。控制只造窗口不造输出，互相瞪眼到 R8。

- 太史慈曹植关羽 [增伤恒 0 + 承伤爆炸]（增伤活跃度 全 0）
  - 增伤开窗：**整场恒 0**——关羽千里单骑是「追击＋自我恢复」、曹植七步释嫌是「降敌伤」、焰焚箕轸是策略伤害但非增伤 buff，三者无一是增伤引擎。
  - 承伤：R2 **5409** / R3 **5661**（全 8 队最高），减伤仅 0.5。
  - **联动诊断**：既无增伤、又无减伤兜底，纯追击菜刀在白板下被秒。胜率 0.9%、承伤 23438 最高。增伤曲线恒 0 是「缺增伤引擎」最直接的数据铁证。

## 三、跨队时序对抗规律（回答「战法之间怎么联动」）

- 规律 A：增伤开窗位置谱系（从厚到零）
  - R1–R3 极厚且对齐爆发：祝融张辽曹操(7.0) > 祝融陆抗曹操(3.0) > 太史慈曹植张辽(1.6)。
  - R5 后发：张春华乐进于禁(1.8)。
  - 薄且 R1–R3 断：吕布张春华甄洛(0.9)、太史慈张春华周泰(0.3)。
  - 恒 0：荀彧张春华曹操、太史慈曹植关羽。
  - 一句话：**增伤开窗的「厚度 × 位置」直接决定胜率高度**，与混战论证增伤链排序完全同构。

- 规律 B：增伤开窗 与 爆发窗口 的对齐度，决定胜负效率
  - 对齐（增伤开窗=爆发窗口）：祝融两队、太史慈曹植张辽（前压型）→ 增伤充分兑现。
  - 错位（增伤后发 R5，但 8 回合上限）：张春华乐进于禁 → 增伤来不及兑现→平局。
  - 这是混战论证「爆发窗口」维度的**回合级解释**：所谓爆发窗口，本质是「增伤引擎开窗的回合区间」。

- 规律 C：瞬发控制(R1) vs 准备控制(R2) 的 1 回合相位差
  - 瞬发（战必断金/强势/反计/落雷）：R1 即生效。
  - 准备（浑水摸鱼/奇术折冲/三术奇谋/焰焚箕轸）：R1 起手、**R2 结算**。
  - 影响：依赖准备控制的队（太史慈周泰靠奇术折冲 R2＋三术奇谋 R2；太史慈关羽靠焰焚箕轸 R2）比瞬发控制队**晚 1 回合**才拿到控制窗——若对手 R1–R2 就爆发，准备控制的 1 回合延迟可能是生死差。

- 规律 D：减伤「覆盖 R1」但「厚度/持续性」才是分水岭
  - 所有队减伤 R1 即起（首减伤回合=1），但厚度天差地别：张春华乐进于禁 R1 2.6→R8 1.8（持续）；周泰队 R1 3.4→R8 0.8（前重后轻衰减）；其余队 <1.0 且薄。
  - 减伤「持续不衰减」的队（张春华乐进于禁）能拖到后期磨死对手；「前重后轻」的队（周泰）后期承伤失控。
  - 这是混战论证「续航兜底」维度的**回合级解释**：兜底 = 减伤/续航在敌方爆发窗之后还能撑住。

- 规律 E：受击触发类（始计）的脆弱性——「优先行动 / 速度」决定增伤是否浪费（v2 已硬编码验证，详见第四节）
  - 始计 R1 100% 发动（行动前触发），给「我军大营**下次攻击** +20%（受谋略，实测约 +30%）」——注意是「单次下次攻击」而非整回合。
  - 张春华基准速度（156）高于吕布（132）也高于太史慈（106），但**实战顺序不等于基准速度**：太史慈带「先驱突击·优先行动」前 3 回合强制先动，把张春华的始计从 R1 推到 R2 才生效。详见第四节硬证据。

## 四、回合内行动顺序精拆：始计到底有没有接上大营（硬编码验证）

> 方法：对含始计的 2 队，逐场从 `BattleReport.events` 重建回合内顺序，判定「大营的攻击是否吃到 shiji 的 caused 增伤」。双保险：修饰铁证（伤害事件 `modifiers.caused` 含 `skillId=shiji`）＋顺序解释（张春华 shiji 触发是否早于大营首次攻击）。数据：`docs/t0t1_action_order.json`（2 队 × 1280 场）。

- 吕布张春华甄洛 [始计接通，但受「单次下次攻击」机制限制]
  - 基准速度：张春华 156 > 吕布 132（张春华更快）。
  - R1 顺序（实测）：始计早于大营 **1127 / 晚于 0** → 速度顺序完美，张春华恒先于吕布出手。
  - 接通率：大营 R1 攻击吃始计 **50.2%**（1904/3790）、前 4 回合 **45%**、整体 **24.8%**（9486/38231）。
  - 关键修正（v2 推翻 v1 推测）：之前怀疑「速度错配导致落空」是错的——吕布的始计**速度上完全接通**；整体只 25% 是因为始计只 buff「大营下一次攻击」单次（吕布 R1 就有辕门射戟 2 击＋普攻≈3.4 次攻击，始计每回合只罩约 1.7 次），并非失效。
  - 时序证据（单场 dump）：R1 `[3] 始计` → `[7] 吕布获得 damage_boost` → `[30] 吕布伤害 caused=[始计@30%,兵种15%]`——接线无误。
  - 偶发延迟：个别回合（如 R2）因于禁「以诱待来」等降速扰动，吕布一度先于张春华出手，该次攻击（caused 仅兵种15%）错过始计→延迟到 R3。属战斗内扰动，非配置错误。

- 太史慈张春华周泰 [始计 R1 完全接不上——「优先行动」覆盖基准速度]
  - 基准速度：张春华 156 > 太史慈 106（张春华更快）。
  - R1 顺序（实测）：始计早于大营 **0 / 晚于 976** → **张春华的始计在太史慈 R1 攻击之后才触发，R1 始计 0% 接通**！
  - 接通率：大营 R1 攻击吃始计 **0%**（0/3416）、前 4 回合 **23.8%**、整体 **17.1%**（2984/17479）。
  - 根因：太史慈携带「先驱突击·优先行动」（前 3 回合强制先动）。这层优先级**覆盖基准速度**，使太史慈永远先于张春华出手 → 张春华的始计只能 buff 到太史慈的 **R2+** 攻击，R1 大爆发被漏掉。
  - 这是用户怀疑的「始计速度脆弱性」的**教科书级铁证**：增伤引擎在、张春华也比大营快，但「优先行动」把时序接线从 R1 切断——始计从「R1 前置增伤」退化为「R2 后才生效」，使这支队的薄增伤（活跃度 0.3）几乎不作用于最关键的开局爆发。
  - 设计启示：若想让太史慈吃到 R1 始计，需给张春华套「优先行动」或把太史慈的先驱突击替换为非优先行动类；否则始计对太史慈是半浪费的。

- 跨队对照结论
  - 同样的「张春华中军带始计、buff 大营」，吕布队（无优先行动）R1 接通 50%、太史慈队（有优先行动）R1 接通 0%——**差的就不是张春华够不够快，而是「大营是否被优先行动/抢速机制顶到张春华前面」这一个机制**。

## 五、断裂 / misfire 检测汇总

- 吕布张春华甄洛：始计**速度上完全接通**（张春华 156 > 吕布 132，R1 始计早于大营 1127/0），整体接通率仅 24.8% 是「单次下次攻击」机制限制而非失效（详见第四节）。
- 太史慈曹植张辽：增伤开窗(R1–R3)存在，但减伤缺失→R3 承伤爆炸(4265)→链在 R3 断裂（被反杀）。
- 太史慈张春华周泰：增伤极薄(始计0.3)＋减伤前重后轻(R1 3.4→R8 0.8)→后期承伤失控。
- 张春华乐进于禁：增伤后发 R5，与 8 回合上限错配→增伤来不及兑现→平局率 52.7%。
- 荀彧张春华曹操 / 太史慈曹植关羽：**增伤曲线整场恒 0** → 增伤引擎根本不存在，是「纯控制/纯减伤乌龟」的时序铁证。

## 六、与混战论证的闭环（最终回答「为什么是 T0」）

- 复证核心定律：时序上「增伤恒 0」的两队（荀彧、太史慈关羽）胜率垫底（0.2% / 0.9%）；「增伤极厚且前压对齐爆发」的祝融张辽曹操胜率最高（42%）。**增伤引擎的有无与厚度，在回合级时序上直接显现**。
- 「爆发窗口」= 增伤引擎开窗的回合区间（规律 B）；「续航兜底」= 减伤/续航在敌方爆发窗之后还能撑住（规律 D）——混战论证的两个「出口」，在本篇被拆成可观测的逐回合曲线。
- 同一祝融核心，有没有「全队大赏三军」这一环，时序增伤厚度差一倍（7.0 vs 3.0），梯队差一档——再次印证 E5「战法因子居首」与「增伤体系是战法因子核心」的衔接。
